## Installation 

If you have your Neovim configuration, make a backup!

```
mv ~/.config/nvim ~/.config/nvim.bak
```

Optional 

```
mv ~/.local/share/nvim ~/.local/share/nvim.bak
mv ~/.local/state/nvim ~/.local/state/nvim.bak
mv ~/.cache/nvim ~/.cache/nvim.bak
```

Clone Repository 

```
git clone --depth 1 https://github.com/krushangptl/nvim ~/.config/nvim/

# remove git connection to setup your own config
rm -rf .git
```

**Use Minimal and Blazing Fast Neovim**

```
nvim
```
